# 어항

공부할 때, 멍하니 있을 때 옆에 띄워 두는 픽셀 도트 어항 게임.

## 올리는 법 (GitHub Pages)
1. GitHub에 새 저장소를 **Public**으로 만든다.
2. 압축을 풀고, 안에 있는 파일을 **icons 폴더까지 전부** 저장소 맨 바깥(루트)에 올린다.
   - `index.html`이 저장소 첫 화면에 바로 보여야 한다. 폴더째로 올리면 안 열린다.
3. Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 정하고 Save.
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 으로 열린다.

## 앱으로 설치
- 게임 안 **메뉴(⋯) → 홈 화면에 앱으로 설치**에 기기별 방법이 나온다.
- 아이폰: 사파리 공유 버튼 → 홈 화면에 추가
- 안드로이드 / PC 크롬·엣지: 메뉴의 "앱 설치" 또는 게임 안 설치 버튼

## 저장
- 저장은 기기(브라우저)에만 된다. 다른 기기로 옮길 때는 메뉴 → 저장 코드 복사 → 새 기기에서 불러오기.

## 업데이트
- `index.html`만 다시 올리면, 인터넷 연결된 상태로 열 때 새 버전이 뜬다.
